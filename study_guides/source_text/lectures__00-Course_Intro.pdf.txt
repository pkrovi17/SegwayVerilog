Course Goals
• Learn how to use Hardware Description Languages (HDL) to design,
  verify, and realize digital logic
• Learn how to synthesize HDLs into hardware using the same tools used
  in industry
• Learn how to effectively work to design a digital system in a team
  environment

• Should be qualified for an entry-level job or internship at an IC design
  firm (AMD, ARM, Intel, Micron, Nvidia, Qualcomm, …) by the end
AI Use
• Allowed to use AI tools
• Transparency
  • Clearly state in submissions use OR non-use
  • State what it was used for
• Need to be able to explain all code

• We will have a small exercise on using AI for design / testing
  • After you know some basics


• You should be able to easily judge whether the AI tool is doing things
  right / well or not
What you should already know…
• Principles of basic digital logic design (ECE352)
  • Number representation (unsigned, signed, Hex & Binary)
  • Boolean algebra
  • Gate-level design
  • K-Map minimization
  • Finite State Machines
  • Basic datapath structures (adders, shifters, SRAM)
  • Some basic ModelSim and verilog from ECE352 AHWs
• How to log in to CAE machines and use a Linux shell

Course Overview
• SystemVerilog basics – how to describe hw blocks
• Simulation Mechanics – making sense of simulation results
• Testbench constructs – create better testing infrastructure
• Synthesis flow
• Area/Delay Optimizations
• Physical Implementations
Course Goals
• Provide knowledge and experience in:
  • Digital circuit design using a HDL (Verilog/SystemVerilog)
  • HDL simulation
  • Good practices in digital design verification
    • How to build self-checking test benches
  • Synthesis of dataflow and behavioral designs
    • Optimizing hardware designs (timing, area, power)
  • Basic static timing analysis concepts
  • Introduce APR (Auto Place & Route)
  • Design tools commonly used in industry

• Teach you to think hardware first! …then code design in HDL
