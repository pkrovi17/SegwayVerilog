Handy Use of fork/join and disable of a Named Block
• A UART transmitter is sending a command to a UART receiver. cmd_rdy will go high
  when the reception is complete.    @(posedge cmd_rdy)
                                           What if cmd_rdy never goes high?
                                           Our test bench will hang!
                     Using fork/join and disable we can make a test bench that
                     will wait for cmd_rdy, but also time out if it never occurs.

• Immediate assertions are evaluated when the statement is reached in the
  testbench flow. They're just a more succinct if + $display self-check.
             assert (result === expected) $display("self check passed");
             else $fatal(1,"ERR: at time %t, result not same as expected",$time);


• Concurrent assertions allows you to define conditions that should always be true
  and are checked at all times during simulation.
                   /// check that rd & wrt are never both asserted   ///
                   /// This will be checked at every simulation tick ///
                   assert property (!(rd && wrt))
                   else $error("ERROR: both rd and wrt asserted to SRAM");


    The keyword property distinguishes a concurrent assertion from an immediate assertion.

• Assertion has a few operators you can use to build more complex checks
  • The implication operator (antecedent |-> consequent): whenever the antecedent sequence
    occurs, the consequent sequence must become true.
  • The delay operator (##): the following sequence starts a set number of clock cycles after the
    current clock tick
    • ##1: one clock later
    • ##[1:2]: one to two clocks later (a range)
    • ##[0:3]: zero to three clocks later (0 means the same cycle)
      req |-> ##[0:3] gnt
 Concurrent Assertions
 • Assertions can get rather complex, don’t have to specify all in one line
    • Can break assertions into multiple parts: sequences, properties, and directive


////Sequence Layer////
sequence req_gnt_seq;               // clock right after req, req
  (~req & gnt) ##1 (~req & ~gnt);   // should be low and gnt should
endsequence                         // be high. Next clock both low

////Property Layer////
property req_gnt_prop;
  @(posedge clk)                    // clk is used for clock ticks
    disable iff (!rst_n)            // will not check when resetting
    req |-> ##1 req_gnt_seq;        // upon req the sequence req_gnt_seq
endproperty                         // specified above should occur

////Directive Layer////
assert property (req_gnt_prop)
else $display("ERR: req_gnt assertion failure at time %t",$time);

• Sometimes we need a way to accelerate the function of a block to make it practical
  to simulate.
• Use a parameter to control whether a block uses its full logic or a faster,
  abbreviated version.

          parameter FAST_SIM = 0;
          ...

            assign next_round = &timer[13:0];   // smaller 14-bit timer

repeat Loops
initial begin
  inc_DAC = 1’b1;
  repeat(4095) @(posedge clk); // bring DAC right up to point of rollover         repeat(3) begin
  inc_DAC = 1’b0;                                                                   ...
  inc_smpl = 1’b1;                                                                end
  repeat(7) @(posedge clk);    // bring sample count up to 7
  inc_smpl = 1’b0;
end

• Good for fixed number of iterations
  • Repeat count can be a variable, but it is only evaluated when the loop starts
    → if its value changes during loop execution, it won’t change the number of iterations
• Handy & succinct way to wait for a fixed number of clocks when used with
  @(posedge clk)

while / do…while Loops
• Executes while the condition is true
  • while → If condition is false from the beginning, it will never execute the loop
  • do … while → always executes 1 iteration first, then check for condition
       reg [15:0] flag; reg [4:0] index;
                                                     Handy for cases where the terminating
       initial begin
                                                     condition is more complex than i<N
