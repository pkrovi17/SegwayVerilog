What is a Hardware Description Language (HDL)?
• Describes the structure and behavior of hardware circuits
• Allows for modeling & simulation (with timing) of digital designs
• Can be synthesized into hardware (netlist) by synthesis tools (Synopsys,
  Cadence, FPGA compilers)
• Two major standards in industry & academia
  • Verilog/SystemVerilog (Flexible, loose, more common in industry)
  • VHDL (Strongly typed, more common in defense and automotive)

Why Use an HDL?
• Enables larger designs – higher level of abstraction
  • Wide datapaths (16, 32, or 64 bits wide) can be abstracted to a single vector
  • Register Transfer Level (RTL) description
  • Synthesis tool does the bulk of the tedious repetitive work
• Portable Design
  • Behavioral or dataflow Verilog can be synthesized to a new process library with
    little effort (i.e., move from 45nm to 22nm process)
  • Verilog in ASCII text can be used by synthesis tools from multiple vendors
• Explore larger solution space
  • Synthesis options and coding styles can help optimize and examine tradeoffs
    (power, area, speed)
• Better Validated Designs

What is a Netlist?
• An ASCII text representation of a schematic
• Many standards exist:
  • SPICE Netlist
  • EDIF (Electronic Data Interchange Format)
  • Structural Verilog Netlist (this is what we will use)

Field Programmable Gate Arrays (FPGAs)
• “Programmable” hardware
• Use small memories as truth tables of functions
• Decompose circuit into these blocks
• Connect using programmable routing
• SRAM bits control functionality
