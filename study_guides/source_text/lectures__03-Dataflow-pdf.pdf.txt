Replication
• Can replicate a signal N times and concatenate together
  • General form: {N{sig}}
  • Example: {3{2’b10}} → 6’b101010
                {2’b00,{3{2’b10}},2’b11} → 10’b0010101011

Supported Operators
• Shifts: <<, >>, >>>
    logic [3:0] A,B,C;
    logic signed [3:0] D;

    assign A = 4’b1001 << 2;           // logical left shift A = 4’b0100
    assign B = 4’b1001 >> 2;           // logical right shift B = 4’b0010
    assign C = 4’b1001 >>> 2;          // arithmetic right shift of unsigned C = 4’b0010
    assign D = $signed(4’b1001) >>> 2; // both src and dst are signed D = 4’b1110


• Relational: <, >, <=, >=
    logic [3:0] A,B;
    assign A = 4’b1111;
    assign B = 4’b0101;

    (A < B)                         // 0 (false), unsigned comparison
    ($signed(A) < $signed(B))       // 1 (true), signed comparison since both operands signed
    ($signed(A) < B)                // 0 (false), unsigned comparison if mixed
    (A > 4’b01X1))                  // X (unknown)

• Bitwise: &, |, ^, ~

Saturation Example
• Assume we have a 16-bit signed sum and want to saturate it to a 12-bit
  signed value for use in downstream calculations.
 • if (sum > 16’h07FF) → 12’h7FF
   else if (sum < 16’hF800) → 12’h800
   else → sum[11:0]
 // use relational operators
 assign sat12 = (sum > $signed(16’h07FF)) ? 12’h7FF :
                (sum < $signed(16’hF800)) ? 12’h800 :
                sum[11:0];
 // use reduction and logical operators
 assign sat12 = (!sum[15] && |sum[14:11])   ? 12’h7FF :
                                                          Smaller faster circuit
                (sum[15] && !(&sum[14:11])) ? 12’h800 :
                sum[11:0];
 // use reduction and bitwise operators
 assign sat12 = (~sum[15] & |sum[14:11]) ? 12’h7FF :
                (sum[15] & ~&sum[14:11]) ? 12’h800 :
                sum[11:0];
