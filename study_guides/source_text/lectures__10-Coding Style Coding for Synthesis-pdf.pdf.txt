case statements
• System Verilog has 4 types of case statements:
  • case, casex, casez, case() inside
• General form: case (expression)
                      item1 : statement1;    // any of these statements could
                      item2 : statement2;    // be a compound statement using
                      item3 : statement3;    // begin/end
                      default : statement4   // always use default for synth stuff
                   endcase

• Performs bitwise match of expression and case item
  • Both must have same bitwidth to match


• case
  • Can detect x and z
  • Good for testbenches & when no wildcards needed

Inter vs Intra Statement Delays
• Inter-assignment delays block both evaluation and assignment
  • #4 c = d;
  • #8 e = f;
• Intra-assignment delays block assignment but not evaluation
  • c = #4 d;
  • e = #8 f;
• Blocking statement is still blocking though
  • Evaluation of next statement’s RHS still comes after assignment of the previous statement’s LHS.
  module inter();                                    module intra();
  integer a,b;         Time    Event                 integer a,b;          Time    Event
  initial begin                                      initial begin
    a=3;                  0      a=3                   a=3;                  0       a=3
    #6 b = a + a;                                      b = #6 a + a;
                          6      b=6                                         6       b=6
    #4 a = b + a;                                      a = #4 b + a;
  end                    10      a=9                 end                     10      a=9
  endmodule                                          endmodule
