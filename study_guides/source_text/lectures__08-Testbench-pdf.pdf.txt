Exhaustive Testing
• Practical for combinational designs w/ up to 8 or 9 inputs
  • Test ALL combinations of inputs to verify output
  • Could enumerate all test vectors, but don’t…
  • Generate them using a for loop!
           logic [4:0] x;        Loop vector needs an extra bit
           initial begin
             for (x = 0; x < 16; x = x + 1)
               #5; // need a delay here!
           end

• Want to test all vectors 0000 to 1111
• If x is 4 bits, you can only go up to 1111
  • X is never >= 16
  • Loop goes forever
Force/Release
• Allows you to “override” value for simulation
• How does this help test?
  • Can create a “short cut” to a state that is difficult to get to through normal paths
  • Examples:
    • Force a state in a SM that would take many sequences to get to through “normal operation”
    • Force an error condition in a protocol if you want to test how your error correction mechanism
      worked
  • Can help achieve code coverage
Force/Release Example
• Toy example showing force/release mechanism


      assign y = a & b;
      assign z = y | c;                T    a b c   y   z
      initial begin                    0    0 0 0   0   0
          a = 0; b = 0; c = 0;
                                       5    0 1 0   0   0
          #5 a = 0; b = 1; c = 0;
          #5 force y = 1;              10   0 1 0   1   1
          #5 b = 0;                    15   0 0 0   1   1
          #5 release y;                20   0 0 0   0   0
          #5 $stop;
      end
