    Exercise 07: Segway Math
    • We are going to implement the math to compute desired speed going
      to the left and right motor

    • A few features we want to embed into speed computation:
      • Soft start: so we don’t “jerk” the platform level on power up
      • Steering input: allows us to turn
      • Compensate for motor dead band: allows small corrections to be
          consistent
      •   Over speed detection: stops rider from leaning too far, beyond the control
          limits

    • The PID control signal should first be scaled by ss_tmr.
    • This ensures a smooth start to the machine, so it does not “jerk” the
      platform level, but rather smoothly drives it to level on power up.
    • ss_tmr slowly ramps up to a full 8-bit value after power up of the Segway.

    • We will use the following structure to perform the shaping computation
        •    If lft_toque is negative (MSB set) then the compensated torque is:
             lft_torque - MIN_DUTY, otherwise it is lft_torque + MIN_DUTY.
        •    If the abs(lft_torque) < LOW_TORQUE_BAND (i.e., we are inside the deadzone), we need to use
             lft_torque*$signed(GAIN_MULT) to form the shaped torque.

     Signed Operations in Verilog
     • Addition and subtraction are agnostic operations
         • An adder to add 2 signed numbers is no different than an adder to add 2
           unsigned numbers
     • Multiplication is not agnostic
         • A multiplier for signed numbers is a little different than a multiplier for
           unsigned numbers.
     • Magnitude comparison is not agnostic
     • Right shifting is not agnostic (arithmetic vs logical)

     • Multiplier will be signed if all three signals are declared as type signed
                 assign product = operand1 * operand2;
     • Magnitude comparison will be signed if both numbers are signed
                 if (num1 > num2)
     • >>> will be signed if both the dest signal and operand being shifted are
       signed
                 assign shifted = operand >>> 3;
