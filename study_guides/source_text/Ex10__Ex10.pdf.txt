    PID Soft Start Timer
    •   The PID unit will also generate the soft start timer (ss_tmr[7:0]) that is
        used in SegwayMath.
    •   We want this ramp of ss_tmr to be in the 2-3 second range. Given our
        clock speed (50MHz), this takes quite a wide timer.
    •   ss_tmr[7:0] will be formed from the upper 8-bits of a 27-bit timer.

    •   The FPGA of the Segway is powered and running initially, but it is waiting
        for a code from the auth_blk (authorization block) to actually enable the
        balancing feature and allow a rider to ride it. When this code comes in
        via a Bluetooth link the pwr_up signal will be asserted.
    •   The counter that forms ss_tmr should be held in a zero state until
        pwr_up is asserted.
