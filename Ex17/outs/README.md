## Summary

This exercise turns the behavioral/dataflow RTL for `balance_cntrl` into a
network of SAED32 standard cells using Synopsys Design Compiler. Constraints
describe the timing environment, external drivers and loads, and estimated
wire capacitance. The tool first compiles the hierarchical design, then
flattens it and compiles again so it can optimize across module boundaries.
The final reports describe area and minimum/maximum timing paths, and the
Verilog netlist describes the mapped gates.

The script explicitly elaborates `fast_sim=0`, selecting the original
hardware integrator scaling and timer increment. Ex17 does not specify a
parameter value; this follows Ex14's instruction to use 0 for hardware.
Changing the script's `fast_sim` setting to 1 synthesizes a different circuit
and can change its area and timing. The reference area in the PDF is an
approximate comparison, not a value to copy into a report.

## Key terms and technologies

- **Logic synthesis / technology mapping:** translate RTL into gates from
  a particular standard-cell library.
- **Standard cell and PVT corner:** a characterized gate and its process,
  voltage, and temperature conditions used for area and timing calculations.
- **Constraints:** the clock, external delays, driver model, output load,
  and transition limit that define the design's operating environment.
- **Wire-load model:** estimates interconnect effects before physical layout.
- **Flattening:** removes module boundaries so optimization can span them.
- **Min/max timing and slack:** shortest/longest modeled path delays and
  the margin relative to their required arrival times.
- **Gate-level netlist:** Verilog instances and connections of mapped cells.

Command reference: the Synopsys-authored *Synthesis Commands* manual is
available through the [UT Austin Synopsys documentation archive](https://users.ece.utexas.edu/~mcdermot/vlsi1/VLSI2_SP_2017/synopsys/doc/Design_Compiler/syn_commands.pdf).
The installed tool's `man`/`help` commands provide the reference for your CAE version.
